# ADR-0006 — Paywall-Linie: Kontroll-Kern Free; Pro = Komfort/Tiefe/Historie
**Kontext:** Prompt §3.4 verlangt ergebnisoffene Prüfung; Analyse in 08 §4.
**Optionen:** (a) Kontrollinfo als Pro-Kern, (b) Kern Free + Komfort-Pro, (c) hybride Gating-Achsen (Vorwarnzeit/Reichweite/Kontingent).
**Entscheidung:** (b). (c)-Achsen ausdrücklich verworfen: Vorwarnzeit = Safety-Gating-Optik; Reichweite = rechnerisch tot (08 §5.2: ~1 sichtbare Meldung in Wochen bei Eigen-Station-Sicht); Kontingente brechen den Melder-Feedback-Loop.
**Konsequenzen:** Pro-Erlös trägt auf Push/Prognose/movement/History/Offline (branchenübliche Achsen); Store-Story verteidigbar; Option C (nur #7/#9 Pro) als revidierbarer Punkt dokumentiert, falls Konversion <1 % nach 6 Monaten. Diese Entscheidung ist zugleich Rechtstrategie (Beihilfe-Narrativ nicht mit Geld koppeln).
